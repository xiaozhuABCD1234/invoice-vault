# 发票管理系统

## 需求分析

1. 需要权限管理（普通用户、管理员）
2. 普通用户上传发票、付款记录（pdf、图片等格式）、系统保存并重命名用户上传的文件
3. 识别系统自动识别提取发票的内容并整理进入SQL数据库
4. 视图功能，需要实现按照用户的要求整理出表头并填报、到出xlsx 表格
5. 检查缺了什么发票、付款记录
6. 生成可视化的图表并导出图片
   
# 技术方案
后端要分领域层、服务层、API层、数据访问层
后端api框架使用fastapi
SQL使用SQLite
ORM框架另选也可以直接用SQL
前端使用vue3+tailwindcss4+Reka UI（shadcn-vue）
